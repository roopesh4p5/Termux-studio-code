Set up everything with one command

Install Termux from F-Droid first, open it, then paste this. It installs the tools, enables the app's Termux access, asks for storage permission and opens the APK installer.

~ — termux
# run inside Termux
$ curl -fsSL https://raw.githubusercontent.com/roopesh4p5/Termux-studio-code/dev/docs/setup.sh | bash
SH setup.sh

The script runs, in order:

  • pkg update and pkg upgrade
  • installs ttyd, git, nodejs, python, openssh
  • sets allow-external-apps=true
  • termux-setup-storage
  • downloads the APK and opens it

01-install-termux.md

Install Termux from F-Droid

Install the F-Droid app, search for Termux, and install it. You can also download the Termux APK directly from its F-Droid page.

F-Droid.apk Termux on F-Droid Termux:API Termux GitHub releases
Don't use the Play Store build of Termux. It's a separate build that doesn't match the F-Droid add-ons. Termux and every Termux add-on must come from the same source (all F-Droid or all GitHub).
~ — termux
# update the package lists and installed packages
$ pkg update -y && pkg upgrade -y
# give Termux access to /storage/emulated/0
$ termux-setup-storage
02-update.md

Update Termux and allow storage

Open Termux and run both commands. If pkg asks you to pick a mirror or keep a config file, press Enter to accept the default.

Tap Allow when Android asks for storage access. Your phone storage then shows up at ~/storage/shared, which lets Termux reach the same project folders the editor opens.

~ — termux
# ttyd powers the integrated terminal in the app
$ pkg install -y ttyd git nodejs python openssh
# tell git who you are (used for commits)
$ git config --global user.name "Your Name"
$ git config --global user.email "you@example.com"
03-tools.md

Install your dev tools

  • ttyd is required for the built-in terminal panel. The app starts it in Termux on 127.0.0.1 with a private token.
  • git, nodejs, python: whatever your projects need. npm run … scripts from package.json show up in the app's Termux menu.
  • openssh is optional, for git over SSH.
The editor also has its own Git built in (status, diff, stage, commit, push), so source control works even before you open a terminal.
~ — termux
# allow other apps to run commands in Termux
$ mkdir -p ~/.termux && echo 'allow-external-apps=true' >> ~/.termux/termux.properties && termux-reload-settings
# check it took effect
$ grep allow-external-apps ~/.termux/termux.properties
04-allow-external-apps.md

Let the app talk to Termux

Termux Studio Code uses Termux's RUN_COMMAND intent to start the terminal server, open a session in your project folder, and run commands like npm test.

Termux only accepts that intent when allow-external-apps=true is set in ~/.termux/termux.properties. The grep should print that line.

~ — termux
# download the APK and open the installer
$ curl -fL -o ~/storage/downloads/TermuxStudioCode.apk https://raw.githubusercontent.com/roopesh4p5/Termux-studio-code/dev/docs/TermuxStudioCode.apk
$ termux-open ~/storage/downloads/TermuxStudioCode.apk
05-install-app.md

Install Termux Studio Code

Use the Download APK button, or run the commands on the left. If Android blocks the install, allow Install unknown apps for your browser or for Termux.

Then open the app and grant:

  • All files access, so the editor can open project folders anywhere on storage.
  • Run commands in Termux environment, prompted the first time you open the terminal. To grant it manually: Settings → Apps → Termux Studio Code → Permissions → Additional permissions.
~ — termux
# optional: keep Termux alive while you code
$ termux-wake-lock
# optional: a projects folder both apps can see
$ mkdir -p ~/storage/shared/Projects && cd ~/storage/shared/Projects
$ git clone https://github.com/you/your-repo.git
06-first-run.md

Open a project and the terminal

  • Ctrl+O opens a folder, for example /storage/emulated/0/Projects/your-repo.
  • Ctrl+` toggles the integrated terminal. It opens a Termux shell in the project folder.
  • Ctrl+Shift+P opens the command palette. Type "Termux" to run npm scripts or a custom command.
On Android 12+, disable battery optimization for Termux (Settings → Apps → Termux → Battery → Unrestricted) so the system doesn't kill the terminal server in the background.

Build the APK on your device

No Gradle and no PC needed. The whole APK builds inside Termux with aapt2, javac, d8 and apksigner, and esbuild bundles the web UI.

~ — termux
# toolchain
$ pkg install -y git openjdk-21 aapt aapt2 d8 apksigner esbuild nodejs unzip
# Android API 34 android.jar
$ mkdir -p ~/android-sdk && cd ~/android-sdk
$ curl -fLO https://dl.google.com/android/repository/platform-34-ext7_r03.zip
$ unzip -jo platform-34-ext7_r03.zip '*/android.jar' -d android-34 && rm platform-34-ext7_r03.zip
# clone and build
$ cd ~/storage/shared && git clone https://github.com/roopesh4p5/Termux-studio-code.git
$ cd Termux-studio-code/codeworkspace
$ bash build.sh --install
BUILD.md

How the build works

  • web/src is bundled with esbuild into the APK's assets. npm deps live in ~/codeworkspace-deps.
  • android/ is a small Java host: splash screen, WebView, and a window.Native bridge for files, search, HTTP and Termux.
  • The pipeline is aapt2 → javac (--release 8) → d8 → zipalign → apksigner.
  • --install copies the APK to Download/ and opens the installer.
Run it with bash build.sh, because shared storage has no exec bit. The signing key is created at ~/.codeworkspace/release.jks. Keep that file: an APK signed with a different key can't update the installed app.

Troubleshooting

The most common setup issues and how to fix them.

PROBLEMS
"Could not reach the terminal server in Termux"

Termux must be installed and running, ttyd must be installed, and external apps must be allowed:

pkg install -y ttyd
grep allow-external-apps ~/.termux/termux.properties   # should print allow-external-apps=true
termux-reload-settings

Then close the terminal panel and open it again.

The permission prompt never appeared

Grant it manually: Settings → Apps → Termux Studio Code → Permissions → Additional permissions → Run commands in Termux environment. Termux must already be installed when you install the app. If you installed Termux afterwards, reinstall Termux Studio Code.

"Termux is not installed" even though it is

You probably have the Play Store build or a mix of sources. Uninstall Termux and its add-ons, then reinstall them all from F-Droid.

Terminal disconnects when I switch apps

Android is killing Termux in the background. Set Termux's battery usage to Unrestricted and hold a wake lock:

termux-wake-lock
The APK won't install over the old version

The signing key changed. Uninstall the old app first. This only happens if you built it yourself with a different key.

The editor can't see my folders

Grant All files access: Settings → Apps → Termux Studio Code → Permissions → Files and media → Allow management of all files.
